## English

### Context & challenge

HVAC Sánchez provides maintenance, installation and technical visits for mini-split air-conditioning systems in the Monterrey area. The goal was to help nontechnical visitors identify an appropriate service and prepare a useful request without having to diagnose their equipment themselves.

Three main needs shaped the website:

1. Explain maintenance, installation and technical visits clearly.
2. Guide people from symptoms or service options toward an inquiry.
3. Distinguish a **price inquiry** from an **on-site appointment request**.

### My contribution

Interface design and implementation, service architecture, JavaScript interactions, conditional forms, responsive behavior, GitHub project organization and Cloudflare deployment configuration.

### Key functionality

- Blue visual identity, legible service cards, navigation and calls to action.
- Guided selection: maintenance, installation, technical visit or assistance choosing.
- **Two form paths:** quotes request essential contact and equipment details; appointment requests add street address and preferred date.
- A review step before the visitor proceeds with the request.
- Responsive interface for mobile and desktop.
- Website files organized as static HTML, CSS and JavaScript.

### Delivery and learning

A complete service website with a catalog, guided inquiries and conditional form behavior. The project reinforced interface development, form validation, responsive layout work and deployment preparation.

**Important scope note:** the website helps prepare requests. Service availability and appointment dates still require confirmation by the technician. No fabricated metrics or automatic booking claims are made.

## Español

### Contexto y reto

HVAC Sánchez ofrece mantenimiento, instalación y visitas técnicas para equipos minisplit en Monterrey y su área metropolitana. El sitio debía orientar a quienes no tienen conocimientos técnicos y organizar los datos necesarios para atender cada solicitud.

El proyecto se centró en **explicar opciones, guiar al visitante y reducir fricción** al diferenciar una cotización de una solicitud de visita.

### Mi participación

Diseño y desarrollo de interfaz, organización de servicios, interacciones con JavaScript, formularios condicionales, adaptación a dispositivos, organización del proyecto en GitHub y configuración técnica para Cloudflare.

### Funcionalidades implementadas

- Identidad azul y celeste con tarjetas de servicios legibles.
- Selección guiada: mantenimiento, instalación, visita técnica o ayuda para elegir.
- **Dos recorridos de formulario:** cotización con datos esenciales; cita con dirección y fecha preferida.
- Campos condicionales y revisión de la solicitud.
- Adaptación responsive para móvil y escritorio.
- Código organizado en HTML, CSS y JavaScript.

### Resultado y aprendizajes

Se entregó un sitio web de servicios con navegación, catálogo y recorridos interactivos de contacto. Fortalecí mis conocimientos de desarrollo frontend, validación de formularios, diseño móvil y preparación de despliegues.

**Límite del alcance:** la web facilita preparar solicitudes; el servicio y la fecha de una visita requieren confirmación por parte del técnico. No se atribuyen resultados comerciales no medidos.
